# 线稿分镜图

## 先报方案（用户要求出图前先看方案时）

用几行写清楚，等用户回一句再开始：

```
场景 A（江边）：3 组 → A1 2×2、A2 2 格、A3 2 格；彩色样张 1 张（A2 的画面）
场景 B（地铁）：环绕运镜拆成 3 个机位 → B1、B2、B3 各 2×2；彩色样张 1 张
合计：6 组线稿 + 2 张彩色样张，共 8 次生图调用。场景 A、B 并行出图。
```

## 会话和并发

- **生图工具有会话概念的**（ChatGPT、Gemini 对话，Codex 线程等）：每个场景开一个会话。会话的第一条消息先交代这个场景的地点、人物、光线和画风，然后再发各组的生成请求。
- **工具没有会话概念的**（一次性的 API、Midjourney 之类）：每次调用都附上同一套参考图和同一段场景描述，用它们来保持一致。
- 不管是哪种，每次调用都重新附上参考图，不要只靠会话记忆。
- **并发**：同一个会话支持并行调用就并行发；不同场景之间并行。并发太多可能遇到容量不足或网络错误，失败的那组单独重试，不要整批重来。

## 每组的提示词

按下面的结构写，每一项都有用处：

```
新画一张图，不是修改之前的任何一张图。
用途：视频分镜线稿，场景 A 的镜头 A1，共 4 格。按从左到右、从上到下的顺序表示时间先后。
画风：黑白线稿，干净的轮廓线，可以用少量灰度表现明暗，不上颜色。画面里不写任何文字，不加对白框；每格左上角只标一个小号数字 1、2、3、4。
版式：2×2 等大格子，每格比例 16:9。格子之间留明显的白色间隔，四周留白。
机位（四格都一样）：全景，侧面平视，人物在画面左侧三分之一处。
运镜：固定机位，镜头不动。
每格内容：
1. （首帧）动作开始前：女主站在画面左边缘，身体朝右，双手垂在身侧，准备迈步
2. 往右走到栏杆前，放慢脚步
3. 停下，右手搭上栏杆
4. （尾帧）站定，右手搭着栏杆，看向对岸（画面右侧）
参考图：图 1 是角色设定图，只参考长相、发型和服装；图 2 是场景参考，只参考环境。
保持不变：人物长相和服装；背景的栏杆、江面和对岸楼群的位置。
```

为什么这样写：

- **"新画一张"**：同一个会话里，生图模型很容易把新请求当成修改上一张图，换镜头时尤其如此。
- **编号、白色间隔、等大格子**：方便后面按格裁开，也能确认格子的顺序。
- **每格比例写成成片比例**（横屏 16:9，竖屏 9:16）：裁出来不用再大幅切边。如果工具出不了这个画布比例，就让每格四周多留一点安全区，裁剪时再切成成片比例。
- **把机位单独写一句，并说明"四格都一样"**：不写的话，模型会让每格的景别和角度各不相同，看起来就不像同一个机位了。
- **有运镜的组，"机位"一行只写不变的部分**（从人物哪一侧拍、镜头高度）；变化写进"运镜"一行，逐格写清楚，例如"第 1 格中景，第 4 格推到近景"，"镜头跟着人物向左移，背景从右往左滑过"。这样生图模型知道每格的差别来自运镜，而不是换了机位。
- **动作拆成每格一句**：一格只画一个瞬间，动作才看得清楚。
- **第 1 格写成动作开始前的状态，并注明首帧**：不写清楚的话，模型常常从动作中间开始画，比如人已经走到一半。这一格之后要精修成正式首帧，画成半截动作，视频一开头就别扭。分镜表里标了尾帧、切点的格，也注明出来，写成稳定、站得住的姿势。没标的格不用注明。

## 格数怎么选

先数这个镜头里要表现几步变化，再选能放下的最小规格：

| 变化步数 | 规格 |
|---|---|
| 1 | 1 格（单张） |
| 2 | 2 格（横屏上下排，竖屏左右排） |
| 3–4 | 2×2（只有 3 步时第 4 格留白，或者画结尾停住的状态） |
| 5–9 | 3×3 |
| 更多 | 再出一张接着画，仍算同一组，编号接着往下排 |

格子越少，每格分到的像素越多，线稿越精细。不要为了省调用次数，把不同镜头塞进同一张图。

## 彩色关键样张

- 单张、整幅出图，不分格。
- 挑这个场景里最能代表氛围的一个画面，写清光线、色调和质感。
- 和这个场景的线稿用同一个会话，这样人物和环境能对上。

## 出图后自查

每张图都看一遍，逐项核对：

- 格数、顺序和分镜表一致，编号对得上
- 第 1 格是动作开始前的起始状态；标为首帧、尾帧、切点的格是稳定的姿势，不是动作做到一半
- 同一张大图里机位没变：景别、角度和人物在画面中的位置，只按设计的运镜变化
- 人物前后一致；左右手、持物和朝向与分镜表一致
- 手指和握法没有明显错误
- 没有混进颜色和文字（编号除外）；格子边界清楚，能裁开

发现不对：只重做那一组。如果问题只在一两格，可以让工具在这张图上只改那几格，并写明其他格保持不变。交给用户时，如实说明还剩哪些问题没解决。
