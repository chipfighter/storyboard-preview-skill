# storyboard-preview：AI 视频的副导演 skill

和 AI 聊完视频创意、准备生成视频之前，让 agent 先帮你做一份分镜预览：文字分镜表、每个镜头一张预览图、带运镜和标注的预览视频。花钱生成视频之前，你就能看懂机位、运镜、转场和节奏，看着预览再改。

适用于 MV、短剧、广告、动画等，原创或有参考视频都可以。只要是能调用生图工具、能看图的多模态 agent 都能用（Claude Code、Codex 等）。

## 它会做什么

1. 你和 agent 聊得差不多、准备开始做时，它一次问清四件事：要不要先确认分镜表？要不要做预览？预览用什么画风（黑白线稿、彩色或别的，不同段落可以不同）？中途在哪里停下来由你拍板？
2. 出分镜表：场景 → 镜头 → 格，写清机位、运镜、动作、左右手、转场、时长和音乐位置。每个镜头下面写"演出"：前景背景的人在做什么、表情和小动作、对面的人的反应、声音；你说过的直接记下，agent 自己补的标成"AI 补的"给你看。
3. 出预览图：**一个镜头只调用一次生图、出一张图，图里 1～4 格。** 固定机位一般 1 格；推拉摇移用几格表现运镜过程（首帧到尾帧）；你强调的表情或动作一定画进去。复杂运镜和转场不靠多画格子，用文字备注说明。每次生图只附这个镜头需要的参考图，避免镜头之间互相串；匹配剪辑这类需要对齐的地方，才附上上一镜要对齐的那一格。
4. 剪预览视频：用 ffmpeg 把图裁成单格，配上音乐，做推、拉、摇、移和设计好的转场。每个镜头左上角标出镜号、景别、运镜，复杂运镜在下方加一行备注，都用你的语言。

预览只给人看，不拿去锁视频模型：测试里，锁给视频模型的图会被几乎原样照搬，图的质感也会原样带进视频。写视频提示词交给配套的 video-prompt skill。

生图工具用你在对话里指定的那个（GPT、Gemini、Midjourney、Codex 等），不会自己换工具。整个流程不开子代理。

## 安装

### 最简单：让你的 AI 帮你装

把下面这句话发给你的 Claude Code 或 Codex：

```
帮我安装这个 skill：https://github.com/chipfighter/storyboard-preview-skill
```

它会自己下载并放到正确的位置。装好以后重开一个对话，正常聊你的视频创意就行，聊完准备开始做时，它会自动用上这个 skill。

### 给 AI 的安装说明

如果你是收到上面这句话的 AI：把本仓库里的 `storyboard-preview/` 整个文件夹（包括里面的 `references/`）复制到用户的 skills 目录，然后告诉用户重开对话即可。

- Claude Code：`~/.claude/skills/storyboard-preview/`
- Codex：`~/.agents/skills/storyboard-preview/`
- 其他 agent：把 `SKILL.md` 当作说明书，`references/` 里的文件放在旁边，按需读取。

剪预览视频需要 [ffmpeg](https://ffmpeg.org/)。用户电脑上没有的话，先告诉用户，问一下要不要装；不装的话，按顺序交付单格图片，再附一张时长和转场表。

### 手动安装

在本页点 **Code → Download ZIP**，解压后把 `storyboard-preview/` 文件夹复制到上面对应的目录。

## 文件

- `SKILL.md`：流程、分岔和核心规则
- `references/shot-table.md`：分镜表和"演出"的格式
- `references/preview-images.md`：每次生图附什么图、提示词模板、格数和版式、出图后快速检查
- `references/animatic.md`：ffmpeg 裁格、运镜、转场、标注和备注、配乐
